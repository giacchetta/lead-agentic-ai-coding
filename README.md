# Lead-Agentic AI Coding

This repository serves as a foundational toolkit for leading Agentic AI in software development projects. It provides a structured set of templates, guidelines, and best practices for defining tasks that can be delegated to AI coding assistants.

## The Philosophy

The core idea is to shift the developer's role from a "Coder" to a "Lead." In this model:

-   **The Human Lead:** Defines the architecture, sets the requirements, specifies the behavior of features and components, and acts as the final code reviewer.
-   **The AI Agent:** Acts as a diligent, fast, but very literal programmer. It takes detailed specifications and generates the corresponding code.

This approach aims to increase development velocity while maintaining high standards for code quality, consistency, and maintainability.

## How to Use This Repository

1.  **Clone or Fork:** Get a local copy of these templates.
2.  **Choose a Template:** Select the appropriate template from the `/templates` directory for the task at hand (e.g., `00_SYSTEM_PROMPT_TEMPLATE.md` to start a new session).
3.  **Fill it Out:** Create a new Markdown file and fill in the template with the specific details for your project. Be as clear and explicit as possible.
4.  **Instruct the AI:** Copy the entire contents of your filled-out Markdown file and use it as the primary context or prompt for your AI coding agent, following the `AI_INTERACTION_PROTOCOL.md`.
5.  **Review and Iterate:** The AI will generate the code based on your spec. Review this code against your requirements and the project's coding standards. Provide feedback to the AI for any necessary revisions.

## Contents

-   **/templates:** Markdown files to be filled out for instructing the AI on specific tasks.
-   **/guidelines:** General rules and protocols, such as coding styles and how to interact with the AI.
-   **/examples:** Filled-out templates for a sample project to demonstrate their practical use.
