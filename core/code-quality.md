# Core Directive: Code Quality & Standards

1. **Clean Code**: Follow clean code principles (SOLID, DRY, KISS). Keep functions small and single-purpose.
2. **Type Safety**: Enforce strict types. Avoid `any` types in TypeScript or un-typed function signatures.
3. **Formatting**: Code MUST strictly adhere to standard workspace formatting rules before completion.
4. **Testing**: Write unit tests for business logic and core edge cases.
