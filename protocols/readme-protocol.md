# Protocol: README.md "Blink" Architecture Standard

## Requirements
- **Visual-First**: Use Mermaid.js flowcharts to illustrate system architecture and data flow.
- **Icons & Structure**: Use concise headers with relevant icons/emojis for fast scanning.
- **Low Text**: Minimize walls of prose. Developers must understand the project in 10 seconds or less.
- **Minimal Setup**: Provide clear, copy-pasteable execution commands (`docker compose up`, etc.).
